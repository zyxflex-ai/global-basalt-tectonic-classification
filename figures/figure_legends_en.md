# English figure legends

**Fig. 1 | Publication-aware data curation and evaluation workflow.** Publication identities were normalized and checked across databases before samples were assigned to publication-level groups. A stratified group split separated the development data from a frozen holdout set without sharing a `CV_GROUP`. The Stable-50 and measurement-coverage criteria were then applied identically to both branches. Model selection used grouped cross-validation only within the development set; the holdout set was used once for final evaluation, publication-level bootstrap analysis and frozen-model SHAP interpretation.

**Fig. 2 | Sample-random splitting substantially inflates apparent model performance.** **a,** Accuracy, balanced accuracy and macro-F1 under publication-grouped and sample-random repeated fivefold cross-validation. Points denote ten repeated partitions per scheme; larger symbols and bars show the median and interquartile range. **b,** Sample-random minus publication-grouped score differences from 2,000 publication-cluster bootstrap resamples per metric; points show medians and bars show 95% percentile intervals. **c,** Class-specific F1 inflation across ten repeated partitions; points and bars show the median and interquartile range. **d,** Fraction of validation samples whose publication group also occurs in the corresponding training fold. Points denote folds across ten repeated fivefold partitions (n = 50 folds per scheme), and black lines show medians. Source data are provided in the validation-bias output tables. Source data include records downloaded from PetDB (https://earthchem.org/petdb) on 11 August 2026; original source citations are provided in the repository attribution tables.

**Fig. 3 | Class-specific performance of the frozen XGBoost model on the publication-group holdout set.** The confusion matrix is normalized within each true class. Each cell reports the row percentage and sample count. Rows are true tectonic settings and columns are predicted settings (n = 10,086 samples). The matrix shows that the principal residual ambiguities involve BABB–MORB, OPB–MORB and several predictions assigned to CFB. Source data include records downloaded from PetDB (https://earthchem.org/petdb) on 11 August 2026; original source citations are provided in the repository attribution tables.

**Fig. 4 | Global geochemical-feature importance in the frozen XGBoost model.** The 12 highest-ranking features are ordered by their mean absolute SHAP value across the 10,086-sample publication-group holdout set and eight class outputs. SHAP magnitudes are expressed on the raw class-margin scale and quantify model attribution strength rather than causal influence. Source data include records downloaded from PetDB (https://earthchem.org/petdb) on 11 August 2026; original source citations are provided in the repository attribution tables.

**Fig. 5 | Class-specific geochemical-feature importance.** **a–h,** The eight highest-ranking features for CAB, IAB, IOAB, BABB, MORB, OIB, OPB and CFB, respectively. Bars report mean absolute SHAP values across all 10,086 holdout samples for the corresponding raw class-margin output. Horizontal scales are independent among panels to preserve within-class rankings; bar lengths should therefore not be compared visually across panels without reference to the axes. Source data include records downloaded from PetDB (https://earthchem.org/petdb) on 11 August 2026; original source citations are provided in the repository attribution tables.

**Fig. 6 | Signed SHAP distributions for arc-related tectonic settings.** **a–d,** CAB, IAB, IOAB and BABB, respectively. Each row contains one point per holdout sample (n = 10,086) for the corresponding class and feature. Horizontal position is the SHAP contribution to the raw class margin; positive values move a prediction toward the class and negative values move it away. Colour represents the original feature value scaled within that feature from low to high, clipped to the 5th–95th percentile range for display; grey denotes missing original measurements. Horizontal ranges are independent among panels. SHAP values describe model attribution, not causation. Source data include records downloaded from PetDB (https://earthchem.org/petdb) on 11 August 2026; original source citations are provided in the repository attribution tables.

**Fig. 7 | Signed SHAP distributions for non-arc and intraplate tectonic settings.** **a–d,** MORB, OIB, OPB and CFB, respectively. Plotting conventions are identical to Fig. 6. Each feature row contains all 10,086 holdout samples; grey points denote missing original measurements, and panel-specific horizontal scales preserve the visible contribution structure. SHAP values describe model attribution, not causation. Source data include records downloaded from PetDB (https://earthchem.org/petdb) on 11 August 2026; original source citations are provided in the repository attribution tables.

**Fig. 8 | Nonlinear class-specific SHAP responses of selected high-ranking features.** **a–h,** CAB–TiO₂, IAB–CaO, IOAB–TiO₂, BABB–SiO₂, MORB–Sr, OIB–TiO₂, OPB–P₂O₅ and CFB–total Fe, respectively. Curves show the median SHAP value in 15 feature-value quantile bins, and shaded bands show the corresponding 25th–75th percentile range. Valid measured-sample counts are 10,078, 10,073, 10,078, 10,086, 8,243, 10,078, 9,929 and 10,077 for panels **a–h**, respectively. SHAP values are on the raw class-margin scale; the curves summarize predictive associations and do not establish causal geochemical controls. Source data include records downloaded from PetDB (https://earthchem.org/petdb) on 11 August 2026; original source citations are provided in the repository attribution tables.

**Fig. 9 | Qualitative comparison with the Pearce–Cann Ti–Zr–Y tectonic discrimination diagram.** **a,** Arc-related classes. **b,** Non-arc and intraplate classes. Only holdout samples with positive measured TiO₂, Zr and Y values are displayed (n = 7,838). Fields A–D are digitized approximations of the empirical boundaries redrawn by Vermeesch (2006) from Pearce and Cann (1973). They are included to visualize overlap in a classical low-dimensional projection and were not used to calculate classification accuracy. Source data include records downloaded from PetDB (https://earthchem.org/petdb) on 11 August 2026; original source citations are provided in the repository attribution tables.
